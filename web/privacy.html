Privacy

What this site counts

Document counts how many times a small set of named events happen each day, such as a page view or a completed action, as totals. It does not record who did what, when a specific visit happened, or anything else that could identify you. There is no anonymous id, no cookie, no local storage, and no third-party analytics script.

The feedback form sends the text you type and the page you sent it from; the server stores them with the time the message arrived. Nothing else is attached to it. Please do not include your name, email, or other personal details in a feedback message.

Your connection

Every page, script, style and font comes from this site; nothing is loaded from another company. To stop abuse, the server limits how many requests one network can make in a short time. For that it uses your IP address (for an IPv6 address, only its network part) while answering the request: Cloudflare keeps a short-lived count in memory, and Document never stores or logs the address. Document keeps no log of ordinary requests: Cloudflare's per-request logs are turned off for this site, and Document's own code logs nothing about who asked or what was sent. Cloudflare, which hosts the site, still handles your IP address to deliver it, as any host does.

One exception: if one IP address sends more than 30 requests to voidvision.org sites in 10 seconds, Cloudflare's firewall blocks it for 10 seconds and records each blocked request (the IP address, the page asked for and the browser's user agent) in the site's security event log, which Cloudflare keeps for a limited time. That log is used only to see and stop abuse.

Retention

Daily event totals are kept indefinitely: a total identifies no one, so there is nothing in it to delete. Feedback text is kept for 90 days, then deleted automatically in batches on days the site is used. If the site goes unvisited for a while, deletion falls behind and catches up once visits resume. Cloudflare D1, the database Document uses, can restore itself to any moment in the last 7 days, so deleted feedback can remain in that restore window for up to 7 more days.

Deletion

Feedback text you sent can be deleted early on request, if you can describe it well enough to find (for example, the page and roughly when you sent it). Use the feedback form on the home page to ask.
