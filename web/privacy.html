Privacy

What this site knows about you

What this site counts

void document counts how many times a small set of named events happen each day, as totals: a page opened, a film watched to its last frame, and an archive's link opened from a film's Sources page. It does not record who did what, when a specific visit happened, or anything else that could identify you. There is no anonymous id, no cookie, no local storage, and no third-party analytics script. The film page remembers nothing between visits, not even your subtitle choice.

The corrections form

The corrections form sends what you type (where in the film, what is wrong, and how you know) and the page you sent it from; the server stores them with the time the message arrived. Nothing else is attached to it. It never asks for your name or email; please leave them, and other personal details, out of what you write.

Your connection

Every page, script, style, font, film, poster, caption file and sources list comes from this site; nothing is loaded from another company. Links to archives, void news and void history take you to those sites only when you follow them, and this site sends no referrer when you do. To stop abuse, the server limits how many requests one network can make in a short time. For that it uses your IP address (for an IPv6 address, only its network part) while answering the request: Cloudflare keeps a short-lived count in memory, and void document never stores or logs the address. void document keeps no log of ordinary requests: Cloudflare's per-request logs are turned off for this site, and void document's own code logs nothing about who asked or what was sent. Cloudflare, which hosts the site, still handles your IP address to deliver it, as any host does.

One exception: if one IP address sends more than 30 requests to voidvision.org sites in 10 seconds, Cloudflare's firewall blocks it for 10 seconds and records each blocked request (the IP address, the page asked for and the browser's user agent) in the site's security event log, which Cloudflare keeps for a limited time. That log is used only to see and stop abuse.

Copies on your device

So the site opens quickly and can be installed as an app, your browser keeps copies of this site's pages, scripts, styles, fonts, icons and posters on your device. They are the same files every visitor gets, and nothing about you is in them. Films, caption files and sources lists are never kept this way, and a film's sources list is checked with the server every time it loads. Clearing this site's data in your browser, or uninstalling the app, removes the copies.

Retention

Daily event totals are kept indefinitely: a total identifies no one, so there is nothing in it to delete. Feedback text is kept for 90 days, then deleted automatically in batches on days the site is used. If the site goes unvisited for a while, deletion falls behind and catches up once visits resume. Cloudflare D1, the database void document uses, can restore itself to any moment in the last 7 days, so deleted feedback can remain in that restore window for up to 7 more days.

Deletion

A correction you sent can be deleted early on request, if you can describe it well enough to find (for example, the page and roughly when you sent it). Use the corrections form to ask.
